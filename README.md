# CONTA FP360 Desktop — Studio y Aula

Aplicaciones de contabilidad educativa para Windows 10 y 11 desarrolladas con **Tauri 2**.

Este repositorio contiene las ediciones **CONTA FP360 Studio** (profesorado) y **CONTA FP360 Aula** (alumnado), basadas en CONTA FP360 v2.1, así como el flujo de GitHub Actions para construir dos instaladores NSIS x64.

**Estado:** código fuente en proceso de publicación. La generación de instaladores se verifica en la pestaña [Actions](https://github.com/atreyu1968/conta-fp360-desktop/actions). Las compilaciones Windows y su funcionamiento offline nativo solo están confirmados cuando termine correctamente el trabajo correspondiente.
